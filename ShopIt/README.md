ShopIt Pro is a **complete e-commerce solution** designed for businesses ready to launch a professional online store. Built with the latest Next.js 16, React 19, and TypeScript, it combines powerful features with exceptional performance.

## 🚀 Quick Start

### 📋 Prerequisites

- Node.js 18.0+ ([Download](https://nodejs.org/))
- npm, yarn, or pnpm
- Git ([Download](https://git-scm.com/))

### 📦 Installation

```bash
# 1. Clone the repository
git clone https://github.com/venkatr95/ShopIt.git
cd ShopItpro

# 2. Install dependencies
pnpm install  # or npm install / yarn install

# 3. Set up environment variables
cp .env.example .env
# Edit .env with your credentials

# 4. Run development server
pnpm dev

# 5. Open your browser
# Visit http://localhost:3000
```

### 🔑 Configuration

The project requires environment variables for external services. See our comprehensive [**SETUP.md**](./SETUP.md) guide for detailed instructions on:

- Creating Sanity CMS project
