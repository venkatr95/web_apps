## Dependencies

### Icons

```
npm install react-icons
```

### ESLint

```
npm i eslint-plugin-unused-imports eslint-plugin-import
```

### Prettier

```
npm install --save-dev prettier prettier-plugin-organize-imports
```

The following command to make the code use prettier rules,
npx prettier --write .
