# FloraLens

FloraLens is an AI-powered plant identification application that helps you unlock the secrets of your garden. Instantly identify plants, get detailed care guides, and discover the history behind every leaf using advanced AI technology.

## Features

- **Instant Identification**: Snap a photo and get results in seconds with high accuracy.
- **Care Guides**: Receive detailed watering, sunlight, and soil requirements for your plants.
- **Secure Access**: Protect your garden journal with PIN-based security.
- **AI Analysis**: Powered by OpenAI to provide comprehensive details about plants.
- **Plant History & Value**: Learn about the history and estimated value of identified plants.

## Tech Stack

- **Frontend**: React, TypeScript, Vite
- **Styling**: Tailwind CSS, Framer Motion
- **Backend/Services**: Supabase (Authentication & Database), OpenAI API (Plant Analysis)
- **Icons**: Lucide React

## Getting Started

For detailed installation and setup instructions, please refer to [Setup.md](./Setup.md).

### Quick Start

1. Install dependencies:
   ```bash
   npm install
   ```

2. Configure environment variables (see [Setup.md](./Setup.md)).

3. Run the development server:
   ```bash
   npm run dev
   ```
