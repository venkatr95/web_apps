# Airbnb Clone

A modern Airbnb clone built with React, TypeScript, and Tailwind CSS.

## Features

- 🏠 Property listings with detailed views
- 🗺️ Interactive maps using Mapbox
- 📱 Responsive design for all devices
- 🔍 Advanced search and filtering
- 📅 Date range picker for bookings
- 👥 Guest selection
- 💖 Wishlist functionality
- 🌍 Multiple language support
- 💰 Currency conversion

## Tech Stack

- React 18
- TypeScript
- Tailwind CSS
- Vite
- React Router
- Zustand
- Mapbox GL
- Supabase
- Lucide Icons

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/clone_airbnb.git
   ```

2. Install dependencies:
   ```bash
   cd clone_airbnb
   npm install
   ```

3. Create a `.env` file in the root directory and add your environment variables:
   ```
   VITE_SUPABASE_URL=your_supabase_url
   VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
   VITE_MAPBOX_TOKEN=your_mapbox_token
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```
